# Калькулятор ОСЭЭК

Онлайн-калькулятор интегрального индекса социально-экономической
эффективности коммуникаций (ОСЭЭК) компаний с государственным участием.

Программа рассчитывает субиндексы медийной устойчивости и социальной
репутации, применяет поправочные коэффициенты риска и масштаба, определяет
значения базового и расширенного контуров индекса, фиксирует статусы
критических ограничений и выполняет имитационную проверку устойчивости
результатов методом Монте-Карло (10 000 итераций, фиксированное начальное
значение генератора).

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Структура

- `app.py` — точка входа и навигация
- `oseec_core.py` — расчетное ядро: формулы (1)–(11), правила работы с
  неполными данными, шкала интерпретации, модуль Монте-Карло
- `page_calc.py`, `page_mc.py`, `page_method.py`, `page_about.py` —
  страницы приложения
- `dadata_api.py` — поиск организации по ИНН (ключ доступа хранится
  только в st.secrets, переменная `DADATA_API_KEY`; без ключа функция
  отключается, расчеты полностью доступны)
- `ui_theme.py` — оформление и графики
- `report_docx.py` — выгрузка протокола расчета в Word
- `tests/test_core.py` — контрольные тесты расчетного ядра
